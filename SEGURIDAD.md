# Política de seguridad

## Informar una vulnerabilidad

No publique detalles de vulnerabilidades en Issues, Discussions ni otros espacios públicos.

Envíe el reporte de forma privada a **colladojohan@gmail.com** e incluya:

- descripción del problema;
- ubicación o flujo afectado;
- pasos para reproducirlo;
- impacto observado o potencial;
- capturas o evidencia que no expongan datos de terceros.

El reporte será revisado y se responderá por el mismo canal. No intente acceder, modificar, eliminar ni descargar información que no le pertenezca.

## Alcance del repositorio

Este repositorio es únicamente informativo. El código fuente y la configuración de producción no se publican aquí.
